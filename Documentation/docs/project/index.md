# Project

The OSHE Pick and Place is a project of the **Open Source Hardware Enterprise (OSHE)** at
Michigan Technological University, under the guidance of Dr. Oberloier: **[oshe.io](https://oshe.io)**.
Michigan Tech's Enterprise program has student teams work on real projects over several
semesters; OSHE focuses on open hardware that can be built in two or three semesters.

The goal: a pick-and-place machine that students and hobbyists can afford and build themselves,
from readily available parts and with no specialized tools.
