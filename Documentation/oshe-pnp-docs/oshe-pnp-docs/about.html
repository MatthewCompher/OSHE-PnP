About & Contributing

Background

This project is run by students at Michigan Technological University as part of the Open Source Hardware Enterprise (OSHE), under the guidance of Dr. Oberloier. Michigan Tech's Enterprise program has student teams work on real projects over several semesters; OSHE focuses on rapid prototyping and projects that can be completed in two or three semesters.

The goal is a pick-and-place machine that students and hobbyists can afford and build themselves, from readily available parts and with no specialized tools.

Roadmap

In progress (V3)

  • Pneumatics: compressor and valve
  • Servo tape feeders on the Arduino Nano
  • First full job run from feeders, then speed tuning
  • Touchscreen job launching
  • V3 bill of materials, wiring diagram and step-by-step assembly guide

Ideas for later

  • More than one toolhead / nozzle
  • More reel space and support for larger reels
  • Front and back loading of reels
  • A soldering module
  • OpenPnP support (the project is currently separate from OpenPnP)

Contributing

Everything is on GitHub: CAD (STEP files for current and past versions), Klipper configuration, pnpvision, pnpslice and the feeder firmware. Feel free to modify any of it. The design currently centers on Ender 3 parts.

  • Report problems or suggest changes with a GitHub issue.
  • Submit changes with a pull request to OSHE-Github/OSHE-PnP.
  • pnpslice and pnpvision have tests that run without hardware; please run them before submitting.

Inspiration

The project draws on other open-source pick-and-place work, especially OpenPnP, LumenPnP, the Index, and Mark Maker's work at makr.zone.
