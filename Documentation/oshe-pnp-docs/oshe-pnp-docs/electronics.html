Stepper cables

Many NEMA 17 motors have a 6-pin connector (2.00 mm pitch) while the board side is 4-pin (2.54 mm pitch). Wire them board → motor as 1→1, 2→4, 3→3, 4→6: straight through except the middle wires, which are swapped. If a motor buzzes or doesn't turn, check this first.

LED wiring tips

LED data lines run next to stepper wires can pick up noise. On the prototype this made the white down-camera light flicker purple, which makes white features look darker to the camera. Fixes:

  • Twist a ground wire with the data wire.
  • Add a 220–470 Ω resistor in series with the data line.
  • Put a 100–1000 µF capacitor across the LED power.
  • Use a 3.3 V → 5 V level shifter (for example 74AHCT125).

Feeder Nano

Servo signal pins are set in Software/feeder_nano/feeder_nano.ino (SERVO_PINS, default 3, 5, 6). Servos are powered from the Octopus 5 V rail, and the Nano's ground must be joined to that ground.

Safety

The machine was designed with the ISO 12100 machine-safety standard in mind, which looks at three things for every hazard:

  • Severity: if someone touches a moving part, it should do as little harm as possible.
  • Exposure: keep the time anyone has to be near a hazard as short as possible.
  • Avoidance: keep hazards separated from the user so nobody reaches into them by accident.

Active safety

The TMC5160 drivers monitor motor load. A sudden rise in load (hitting the frame or a hand) can trigger a stop. This is the same mechanism used for sensorless homing. Software current limits also cap motor torque, speed and heat.

Emergency stop

Wire a normally-closed e-stop in the +24 V line between the power supply and the board's power inputs, so pressing it cuts power to everything after the supply. The supply itself stays live, so switch off and unplug the supply before any maintenance. The e-stop also ends a running job.

Passive safety

  • Belts run inside the extrusion slots where possible, so nothing gets caught.
  • Rounded corners and flush edges on moving parts to avoid pinch points.
  • Electronics and pneumatics are kept away from where hands go.
  • Don't jog or run other macros while a job is running: the job moves the machine itself.
