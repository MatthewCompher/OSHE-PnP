Software Stack & Klipper Setup

The machine runs a 3D-printer software stack adapted for SMT assembly, plus two programs written for this project: pnpslice (on your computer) and pnpvision (on the Pi).

1. Install MainsailOS on the Pi

  1. Download and open Raspberry Pi Imager.
  2. Choose Device: Raspberry Pi 4.
  3. Choose OS: Other specific-purpose OS → 3D printing → Mainsail OS (latest).
  4. Choose Storage: your microSD card.
  5. When asked about OS customization, choose Edit Settings and set the hostname, username and password, and your Wi-Fi.
  6. Write the card, put it in the Pi and power on. After a minute or two, open http://<hostname>.local in a browser to reach Mainsail.
The prototype uses hostname PnP and user pnp, with the repository cloned to /home/pnp/OSHE-PnP. Some scripts and macros (VISION_HOME, RUN_JOB) use those paths. If you choose different names, update the paths in printer.cfg, pnp_hmi.cfg and Software/pnpvision/scripts/.

Then, on the Pi:

cd ~
        git clone https://github.com/OSHE-Github/OSHE-PnP.git

2. Flash Klipper onto the Octopus Pro

Don't leave anything connected to the heater outputs (HE0/HE1) when flashing for the first time: the board may switch all heaters and fans on at first power-up.
  1. SSH into the Pi (ssh pnp@PnP.local) and open the firmware menu: 
    cd ~/klipper
        make clean
        make menuconfig
  2. Turn on Enable extra low-level configuration options, then set the options for your board's chip (it is printed on the board and in its product name):
    SettingOctopus Pro H723 (this machine)Octopus Pro F446
    Micro-controller architectureSTMicroelectronics STM32STMicroelectronics STM32
    Processor modelSTM32H723STM32F446
    Bootloader offset128KiB bootloader32KiB bootloader
    Clock reference25 MHz crystal12 MHz crystal
    Communication interfaceUSB (on PA11/PA12)USB (on PA11/PA12)
  3. Press Q, save, and build: make
  4. Rename the result and copy it to a FAT32 microSD card: 
    mv out/klipper.bin out/firmware.bin
  5. Power off the Octopus, insert the card, and power on. It flashes itself in a few seconds.
  6. Check it worked: ls /dev/serial/by-id/ should list a usb-Klipper_stm32… device. Copy that path into [mcu] serial: in printer.cfg.
⚠ Verify: the H723 settings match BIGTREETECH's published Klipper settings for that board. Check against the BTT Octopus Pro docs before flashing. For DFU flashing and updates, see the Voron Octopus Klipper guide.

3. Flash Klipper onto the Uno (second MCU)

The Uno R3 adds extra outputs (currently the up-camera ring light). It uses a separate build configuration so it doesn't overwrite the Octopus settings:

cd ~/klipper
        make menuconfig KCONFIG_CONFIG=config.uno    # Atmega AVR, atmega328p; turn off optional features so it fits
        make KCONFIG_CONFIG=config.uno
        make flash KCONFIG_CONFIG=config.uno FLASH_DEVICE=/dev/serial/by-id/usb-Arduino...

Put the Uno's serial path into [mcu uno] serial: in printer.cfg (it uses restart_method: arduino).

4. Install extensions

  • klipper-led_effect (github.com/julianschill/klipper-led_effect): needed for the LED macros.
  • G-Code Shell Command: install with KIAUH (main menu → Extensions → G-Code Shell Command; decline the example config). Needed for VISION_HOME and RUN_JOB.
  • crowsnest and KlipperScreen: usually included with MainsailOS.
  • Obico (optional, remote monitoring). If you don't use it, remove [include moonraker_obico_macros.cfg] from printer.cfg.

5. Install printer.cfg

Copy Software/Klipper/printer.cfg and pnp_hmi.cfg into ~/printer_data/config/. Then update:

  • [mcu] and [mcu uno] serial paths.
  • Pins, if your wiring differs from the pin map.
  • Travel limits, if your frame is a different size.

Edit it in Mainsail under Machine → printer.cfg → Save & Restart. Reference copies of the other files on the prototype Pi (moonraker.conf, crowsnest.conf, KlipperScreen.conf and more) are in Software/Klipper/from-pi/.

Before the first move:

  • Check every motor is in the slot the config expects.
  • Jog each axis a small distance at low speed and check the direction.
  • Test homing at low speed, one axis at a time (G28 Z, then G28 Y, then G28 X).

To save changes made on the Pi back into the repo (run on your PC):

scp pnp@PnP.local:~/printer_data/config/printer.cfg path/to/OSHE-PnP/Software/Klipper/printer.cfg

6. Set up the cameras and vision

Configure crowsnest (Moonraker → Cameras), then install pnpvision and calibrate (Vision).

Troubleshooting

ProblemWhat to check
TMC driver registers all read zeroThe board needs 24 V, not just USB power: Klipper reports a communication failure when the drivers are unpowered. Then check SPI jumpers, CS pins, and the MISO line.
Motor doesn't move or moves wronglyDriver slot vs. config, cable wiring order (see stepper cables), CS pin.
Homing stops early in mid-airStall detection too sensitive: raise homing current toward 1.0 A or raise driver_SGT by 1. On the prototype, 20 mm/s or 0.8 A false-triggered; 40 mm/s at 1.0 A works.
Homing crashes into the frameWrong motor direction or stall detection not sensitive enough. Test slowly.
Jerky motion or skipped stepsLower velocity/acceleration, check belt tension, check nothing binds.
Nothing powers onIs the e-stop pressed? Check supply output and crimps.
Pi freezes during installsOut of memory (1 GB). Use SSH + tmux, stop KlipperScreen temporarily, install OpenCV with --only-binary=:all:.
