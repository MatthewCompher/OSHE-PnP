How to Build

This guide gives the order of the V3 build, from a donor Ender 3 to a first placed board. Each stage links to the page with the details.

⚠ Verify: step-by-step V3 assembly instructions (with hardware counts per step) are still being written. Stages marked details to come list what's needed and which CAD folder to use. For a fully written-out (older) build, see the V2 guide linked from History.

1. Gather tools and materials

Tools

  • Metric hex key set (most hardware is M3 and M5)
  • Metric wrench set
  • Needle-nose pliers
  • Wire strippers and crimpers (for connectors and belt crimps)
  • Soldering iron (for heat-set inserts)
  • A 3D printer that can print large parts

Materials

  • A Creality Ender 3 (a broken one is fine) for extrusion, motors, belts and hardware
  • PETG and PLA filament
  • Plenty of M3, M4 and M5 T-nuts, plus the hardware in the BOM
  • Electronics: see Electronics
⚠ Verify: V3 filament amounts (V2 needed at least 2 kg PLA and 1 kg PETG).

2. Print the parts

Print everything in CAD/V3-Active. PETG is preferred for structural parts. Use 0.2 mm layers, 2+ perimeters, 12% gyroid infill and tree supports. See 3D printing.

3. Take apart the Ender 3

  1. Unplug the printer and disconnect the power supply.
  2. Remove the top bar, then the Z-axis lead screw and motor.
  3. Remove the two bolts at the front of the base to reach the control board, and the two bolts holding the LCD.
  4. Unbolt the extrusions from each other. Keep the extrusion, stepper motors, belts, pulleys, rollers, fan and all bolts and T-nuts. Factory holes in the extrusion can be ignored.

Be careful with ribbon cables and don't yank any wires.

4. Build the frame

Assemble the four legs from the bottom, middle and spacer pieces (mirror pairs A and B), and join them with the 4040 extrusion and 4040 spacers. Make sure the frame is square before moving on: an out-of-square frame causes position errors later.

Details to come.

5. Install the CoreXY motion system

Mount the two motors in the motor corners and the idlers in the idler corners, fit the X carriage, then run the two belts in the CoreXY pattern and tension them with the printed tensioners. Belts should be firm but not over-tight.

Details to come.

6. Build and mount the toolhead

Assemble the LumenPnP-style toolhead with its CP40 nozzle holder and NEMA 11 rotation motor, mount the down camera, and attach it to the X carriage. Start with the N08 tip.

Details to come.

7. Build the staging plate

  1. Assemble the plate tiles (with the camera tile over the up camera) on the brackets and spacers.
  2. Mount the up camera and its LED ring under the camera tile.
  3. Fix the camera datum and PCB mounts to the plate. The datum must not move after calibration: if it does, visual homing and every step after it must be redone.
  4. Add the reject bin.

Details to come.

8. Build the feeders

Assemble each 0816 feeder with its servo, and connect the servos to the Arduino Nano (signal pins 3, 5 and 6 by default). Power the servos from the controller board's 5 V rail and join the Nano's ground to it. Follow the original 0816 feeder documentation for the mechanism.

Details to come.

9. Install the pneumatics

Mount the compressor and valve, run the tubing to the toolhead, and wire the valve to the FAN1 header.

Details to come.

10. Wire the electronics

Follow Electronics & Safety: Octopus Pro board, drivers, motors, Raspberry Pi 4, cameras, LEDs, Uno, Nano and the emergency stop. Double-check every motor's driver slot and wiring order before powering on.

11. Install the software

Follow Software: MainsailOS on the Pi, Klipper on the Octopus Pro and the Uno, the repository's printer.cfg, then crowsnest and the cameras. Check each axis moves the right way at low speed before homing.

12. Calibrate

  1. Check the frame is square, belts are tensioned and every axis moves freely.
  2. Test homing at low speed. Tune sensorless homing if it stops early or crashes.
  3. Run the camera and vision calibration in order: see Vision → Calibration.

13. Run a first job

  1. Make a job file from your KiCad board with pnpslice.
  2. Align the board and do a dry run (photos only, no parts).
  3. Run the job on a few parts first. See Vision → Running a job.
