pnpslice: KiCad to Job File

pnpslice is a "slicer" for the pick-and-place, like a 3D-printer slicer. Open a KiCad board, check it, slice each side, step through the result, and export a job file for the machine. It runs on your own computer (Windows, macOS or Linux). The code is in Software/Slicer, with a full User_Guide.md.

What it does, and doesn't do

pnpslice does (board side)The machine does (pnpvision)
Reads the .kicad_pcb (KiCad 6 or newer): parts, pads, outlineHomes with vision
Converts KiCad coordinates to the board frameFinds the board on the plate
Works out each part's pick point, rotation and heightConverts board coordinates to machine coordinates
Checks for problemsChooses feeders, Z heights and nozzle tips
Orders the placementsChecks each part on the nozzle and corrects it
Chooses 2–4 alignment padsRetries missed picks, uses the reject bin, logs everything

The job file never contains machine coordinates, Z heights, feeder positions or G-code, because those depend on where the board lands and on the machine's calibration. Only SMD parts are placed. Through-hole parts and parts excluded from position files are skipped; Do-not-populate parts stay in the file, marked to skip.

Install

You need Python 3.10 or newer (3.12 or 3.13 recommended).

Quick start (VS Code)

  1. Open the Software/Slicer folder in VS Code.
  2. Open run.py and click Run.
  3. The first time, it offers to install PySide6 (the Qt toolkit, about 100 MB). Press Enter.

To always open your own board, set BOARD = r"C:\path\to\board.kicad_pcb" at the top of run.py. Set MODE = "text" for a terminal summary instead of the window.

Full install (with tests)

# Windows (PowerShell)
        cd path\to\Slicer
        py -m venv .venv
        .venv\Scripts\Activate.ps1

        # macOS / Linux
        cd path/to/Slicer
        python3 -m venv .venv
        source .venv/bin/activate

        # then
        python -m pip install --upgrade pip
        pip install -e ".[gui,dev]"
        pytest

If PowerShell refuses to run the activate script, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once.

Using the window

  • Prepare and Preview (top bar) switch between setting up and checking the result.
  • Plate 1 · Top / Plate 2 · Bottom switch sides. The bottom is shown mirrored, as seen from below.
  • Mouse wheel zooms; drag empty space to pan; F or double-click fits the board.
  • Click a part, or its row in the parts table, to select it.
  • Ctrl+O opens a board (or drag a .kicad_pcb onto the window). F5 reloads after you save in KiCad.

Part heights

The runner needs each part's height to know how far down to place it. pnpslice takes the first of: (1) a height you entered with Edit heights…, (2) a Height field on the KiCad footprint, (3) a built-in typical height for common packages. If none exists, slicing is blocked. Typical heights are only a starting point: check capacitors especially, since they get taller at higher values. Your heights are saved per board in <board>.pnpslice.json.

Alignment pads

Before placing, the machine centers its down camera on each alignment pad to find exactly where the board is and how it's rotated. Good pads are:

  • Visible: copper with a solder-mask opening on the placed side.
  • Distinct: no similar pad within 3 mm (the "look-alike clearance").
  • Spread out, near opposite corners, not in a line. Three is recommended.
  • Never covered, ideally: fiducials first, then pads of parts that aren't placed.

pnpslice picks them automatically. To choose yourself, click Pick by hand: distinct pads turn green, look-alikes red. Click to add or remove; Auto goes back. Pad A is the one nearest the origin.

Slice, preview, export

  1. Slice plate (Ctrl+R). If anything blocks it, the Problems list says what and how to fix it.
  2. Preview: drag the slider or use ↑ ↓ to step through the order.
  3. Export job… (Ctrl+E) saves <board>-top.job.json or <board>-bottom.job.json.
  4. Copy the job file to the Pi, into Software/pnpvision/jobs/.

Placement order

Lowest parts first, then smaller packages, one package at a time, with the shortest path within each group. That way the nozzle never meets a taller part that's already placed.

Blocking errors

  • Duplicate or unnumbered references (unless Auto-number duplicate references is on)
  • A pick point outside the board outline
  • A package with no height
  • No parts on that side

The job file format

Job files follow oshe-pnp-job/1, defined in Software/pnpvision/JOB_FORMAT.md. It's the contract between the slicer and the machine: any program that writes this format can feed the machine.

The board frame

  • Seen from above the side being placed.
  • Origin at the lower-left corner of the outline's bounding box; +X right, +Y up. All lengths in mm.
  • Bottom-side jobs are mirrored so they read as if the bottom were the top.
  • Angles in degrees, counter-clockwise positive, from the footprint's library orientation.

Fields

FieldContents
formatAlways "oshe-pnp-job/1"
boardname, side (top/bottom), outline_mm, thickness_mm
alignment2–4 pads: name, x, y, shape, size, optional ref/pad
placementsIn order: ref, value, package, x, y, rot, height_mm, optional feeder, nozzle, skip
sourceOptional: generator, input files, date
