OSHE Pick and Place

The OSHE Pick and Place is a low-cost, open-source machine that places surface-mount components onto printed circuit boards. Commercial pick-and-place machines are expensive and mostly found in industry. This project brings automated PCB assembly within reach of students, small labs and hobbyists.

It was built by students in the Open Source Hardware Enterprise (OSHE) at Michigan Technological University. The machine starts from the parts of a Creality Ender 3 3D printer (aluminum extrusion, stepper motors and hardware) and adds 3D-printed structure, a vacuum toolhead, cameras and its own software. You can build it without special tools.

Work in progress. V3 (Fall 2026) is the current version and is still being developed. Some sections of this site are marked as incomplete or "to be confirmed".

How it works

A board goes from design to placed parts in five steps:

  1. Design the board in KiCad.
  2. Slice it with pnpslice, which turns the .kicad_pcb file into one job file per board side.
  3. Align the board on the machine: pnpvision uses the down camera to find the board's exact position and rotation.
  4. Pick, inspect and place: for each part, the nozzle picks it from a feeder, the up camera checks how it sits on the nozzle, and the machine corrects the offset and angle before placing it.
  5. Motion is carried out by Klipper, driven through Moonraker.
